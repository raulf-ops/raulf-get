## 🗺️ NexSap — Deep Dive

<div align="center">

<img src="https://img.shields.io/badge/Platform-Android-3DDC84?style=for-the-badge&logo=android&logoColor=white"/>
<img src="https://img.shields.io/badge/Status-In%20Development-6E40C9?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Type-Mobile%20App-0D1117?style=for-the-badge"/>

</div>

<br/>

### 🎯 The Idea

Most map apps all look the same.  
**NexSap** asks a simple question:

> *What if exploring the real world felt like exploring a video game map?*

NexSap takes real-world location data and renders it in **creative,  
game-inspired map styles** — so a walk around your neighbourhood  
feels like an open-world adventure.

### ✨ Features

| Feature | Description | Status |
|:---|:---|:---:|
| 🗺️ **Custom map styles** | Multiple visual themes for the same real-world map | 🚧 |
| 📍 **Live location** | See where you are in real time on the styled map | 🚧 |
| 🔍 **Explore places** | Discover real-world locations around you | 🧪 |
| 🎨 **Theme switcher** | Change the look of the map in one tap | 🧪 |
| 🧭 **Minimap mode** | A compact, game-style minimap view | 💡 |
| 🏷️ **Custom markers** | Icons for points of interest, styled per theme | 💡 |
| 🌙 **Day / night mode** | The map changes with the time of day | 💡 |
| 📤 **Share screenshots** | Share your styled map with friends | 💡 |

<sub>🚧 In progress · 🧪 Experimenting · 💡 Planned · ✅ Done</sub>

### 🧱 How It's Built

```text
┌─────────────────────────────────────────────┐
│                  NexSap App                  │
├─────────────────────────────────────────────┤
│  UI Layer        → screens, theme switcher   │
│  Map Layer       → map rendering + styles    │
│  Location Layer  → GPS / real-time position  │
│  Data Layer      → places & points of interest│
└─────────────────────────────────────────────┘
```
